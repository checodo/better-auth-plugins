Use these assets when you write about better-auth-plugins, link to it, or
show that your project uses one of its plugins.

<Callout title="A community project">
  better-auth-plugins is not part of better-auth and not made by its team.
  Don't use this logo in a way that suggests it is official better-auth
  work, and don't combine it with better-auth's own logo into a new mark.
</Callout>

## Logo

The mark is three staggered squares and a lime square that is being
plugged in. All four squares are the same size and sit on one grid, so the
mark is exactly square.

<LogoPreview />

Use the dark mark on light backgrounds and the inverted mark on dark ones.
The lime square stays the same on both.

## Logo with name

The full logo, with the name as outlines, so it looks the same everywhere.
Use it where there is room, such as a README, a slide, or a banner.

<FullLogoPreview />

In a user interface, such as a navigation bar, you can set the name as
text instead: make the mark about 1.3 times the font size (a 24 px name
gets a 32 px mark), with a gap of half the font size, and use
[Geist](https://vercel.com/font) semibold, in lowercase, exactly as
`better-auth-plugins`.

<LockupPreview />

## Colors

<ColorSwatches />

Lime on a light background has too little contrast for text, so use it
only for the accent square and other decoration, never for words.

## Usage

- Keep clear space around the mark of at least one square (a third of its
  width).
- Don't show the mark smaller than 16 pixels.
- Don't recolor, rotate, stretch, outline, or add effects to the mark.
- Don't move the squares or change the lime square's position.
- Write the name in lowercase, with hyphens: `better-auth-plugins`.

## Typography

The docs use [Geist](https://vercel.com/font) for text and Geist Mono for
code.
